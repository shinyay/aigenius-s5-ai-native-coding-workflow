# Agent Merge 補足ガイド

[English](README.md) | 日本語

[単一ファイルのHTML教材](index.html)で、Copilot AppのAgent Mergeの機能、利用手順、ユースケース、人間に残る判断を紹介します。既定は日本語で、**English**への切り替えやURLによる言語指定に対応します。

中心メッセージは「条件を決める。仕上げを任せる。」です。[Copilot App DXガイド](../copilot-app-dx/README.ja.md)とは独立した補足教材であり、コア演習の「最終差分を人間が確認し、手動マージする」方針は変更しません。

## 内容

- 人間、エージェント、GitHubの役割を示す受け渡し図
- レビュー対応、CI修正、競合解消から取り込みまでの概念的なループ
- My workからPRの作業セッションを開き、Agent mergeへ進む模式的な操作案内
- 5つの架空PRシミュレーション
- 具体的な利用シーンと、取り込みまで任せない方がよい場面
- 必須チェック、承認、変更後の再承認、権限、デプロイへの影響
- 発表用の一言、公開出典、ブランドとフォントのライセンス

## 表示方法

リポジトリをcloneした後、`presentation\copilot-app-agent-merge\index.html`をブラウザーで開きます。GitHubのファイル閲覧画面はHTMLのソース表示であり、ホストされたプレビューではありません。

GitHub Copilot Appでは、次のように依頼します。

```text
presentation\copilot-app-agent-merge\index.htmlをBrowser Canvasで表示してください。
```

既存のBrowser Canvasを使います。新しいCanvas extensionの導入や、スライドプレゼンターの変更は不要です。

ホストがローカルHTMLを開けない場合に限り、兄弟配置の両ガイドへ移動できるよう、共通の`presentation`ディレクトリをloopbackで配信します。リポジトリルートのPowerShellで次を実行します。

```powershell
uv run --no-project python -m http.server 8765 --bind 127.0.0.1 --directory ".\presentation"
```

Browser Canvasで、このガイドは`http://127.0.0.1:8765/copilot-app-agent-merge/`、DXガイドは`http://127.0.0.1:8765/copilot-app-dx/`を開きます。片方のガイドディレクトリだけ、またはリポジトリルート全体は配信しません。ポートが使用中なら未使用のものを選び、無関係なプロセスは停止しません。サーバーはターミナルに紐づけ、終了時はCtrl+Cで停止します。GitHub Pagesなどへの公開は不要です。

## ガイド間の移動

共通ヘッダーの**DXガイド / Agent Merge［補足］**で、同じCanvas・ブラウザータブ内の各ガイドの先頭へ移動します。下線付きの現在のガイドを選ぶと、このページの先頭へ戻ります。ワークショップの章のDXリンクは境界の章へ、DXの自動化に関する説明直後のリンクはこの補足の機能紹介へ戻ります。ブラウザー標準の戻る・進むを利用できます。

JavaScript有効時は、固定の相互リンクだけに表示中の`lang=ja|en`と`scoutTheme=light|dark`を付けます。言語・テーマの操作や、追従対象のOSテーマが変わるとリンクも更新します。無関係のクエリー値やシミュレーションのデータは渡しません。URLの有効な言語は翻訳カタログの準備後に適用します。言語の未指定・不正値は日本語、テーマの未指定・不正値はOSに従います。英語を利用できない場合は理由を表示したまま、日本語の値を渡します。

再読み込みは最後の操作ではなく、現在のURLにある表示設定を使います。操作ボタンはそのURLを書き換えません。有効なURL指定がなければ日本語・OSテーマで再開し、シミュレーションは最初のケースへ戻ります。Cookie、localStorage、sessionStorageなど、ブラウザーの保存領域への書き込みはありません。別の文書へ進行状態は渡さず、ブラウザー標準の履歴復元も妨げません。

## 閲覧とシミュレーション

| 操作 | 動作 |
|---|---|
| 日本語 / English | 本文、図解ラベル、操作名、動的な状態、読み上げ用ラベル、文書情報を切り替える |
| テーマボタン | 表示中のページのlight/darkを切り替える |
| 章ナビゲーション | 読みたい章へ移動する。狭い画面では折り畳みになる |
| ケース選択 | 選択した架空PRの初期状態へ移る |
| 次のステップ | 教材の処理を1段階だけ進める。自動再生はない |
| 人間の承認を模擬する | 必要な場面で、現在の架空コミットへの人間の承認を追加する |
| リセット | 選択中のケースだけを初期状態へ戻す |
| 発表用の一言をコピー | 現在の言語の文章をコピーする。利用不可なら本文を選択して手動コピーを案内する |
| 印刷 | 現在の言語で補足を展開し、操作部品を除いて印刷する |

同じページ内で言語やテーマを切り替えても、選択したケース・進行状態・現在の架空コミットに対する模擬承認を維持します。

OSのテーマを初期値に使い、`?scoutTheme=light`または`?scoutTheme=dark`で指定できます。JavaScript無効時も日本語本文・図解・相対リンクによるガイド間の移動・標準の折り畳みは既定のライト表示で利用できます。URLの表示設定は適用せず、言語・テーマ・印刷ボタンとシミュレーションは使えません。ブラウザー標準の印刷は利用できます。

## 5ケースの前提

| ケース | 学ぶ内容 |
|---|---|
| すでにReady | 修正が不要なら、取り込みが主な残作業になる |
| レビュー対応 | 修正でコミットが変わり、CIと人間の再承認が必要になる |
| CI失敗 | 失敗原因を修正し、現在のコミットに対する成功を得る |
| 競合解消 | 以前の成功を新しい評価対象の結果として使い回さない |
| 必須承認待ち | 「次へ」だけでは進めず、人間の明示的な模擬承認を待つ |

すべてのケースでpytestの成功を必須と仮定します。Ready・レビュー対応・承認待ちでは、人間の承認も必須です。CI失敗と競合解消では、承認レビューを必須にしていない例として、その前提を画面に明示します。

チェックと承認は架空のコミット識別子に結び付けます。失敗、実行中、古い結果、未解決の指摘、競合、必要な承認の不足がある状態は、教材内でもMergedへ進めません。

**この教材はGitHubへ接続しません。** 状態、履歴、承認、Mergedの表示はすべて架空です。実製品の内部実装・待機間隔・成功保証を再現するものではありません。実際のAgent Mergeの有効化、PR作成、コメント、承認、push、マージは行いません。

## 更新方法

静的な日本語はHTMLの`data-i18n`を付けたテキスト要素を原本にします。英語は`#english-translations`の`strings`です。読み上げ用ラベルは`data-i18n-aria`に対応します。翻訳対象に子要素を入れず、インラインの装飾が必要なら対象を分割します。

動的メッセージは`jaUI`と英語カタログの`ui`を一緒に更新します。キーの不足・余剰・不一致は初期化時に検出し、英語を無効化して理由を表示します。翻訳文はHTMLとして実行せず、テキストとして反映します。

相互リンクの行き先はナビゲーション処理で固定します。文字と読み上げ用の名前を翻訳し、カタログから行き先を受け取ったり、任意のクエリー値を転送したりしないでください。

シミュレーションは`scenarios`、状態は`state`で管理します。`evidenceReady`、`canMerge`、`canApprove`の条件を維持し、ケースの変更時には説明文とルールの前提も揃えます。模擬承認を新しいコミットへ暗黙に引き継いではいけません。

変更後はブラウザーで5ケースの状態遷移、日英の往復、light/dark、狭い画面、キーボード、動きの抑制、コピーと手動フォールバック、印刷、JavaScript無効時を確認します。実行時に外部へアクセスせず、HTMLはフォント・ライセンス込みで400KiB以内を維持します。

製品説明は公開資料、UIの模式図は観察、ユースケースは教材上の提案として区別します。仕様の更新時はHTMLの出典と参照日も更新します。既定のマージ方式や処理間隔など、不明な事項を推測で断定しません。
