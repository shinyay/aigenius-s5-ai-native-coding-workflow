# Copilot App Developer Experience ガイド

[English](README.md) | 日本語

GitHub Copilot Appの価値を、オーディエンス向けに日本語・英語で読み解く[スクロール型HTMLガイド](index.html)です。中心に据えるのは、コード生成の速さだけでなく、仕事の委譲、根拠の確認、人間による採用判断です。

Agent Mergeの機能・利用手順・ユースケースは、独立した[Agent Merge補足ガイド](../copilot-app-agent-merge/README.ja.md)で詳しく紹介しています。オフラインの架空PRシミュレーションを含み、このガイドやコア演習の手動マージ方針は変更しません。

## 内容

- 伝えたい主題と、タスクを中心とした開発ループ
- 具体例、話す一言、注意点を添えた6つのDeveloper Experienceの変化
- App、cloud agent、Codespaces、Chat、CLI、github.comの役割分担
- 受入条件、境界値、不変条件、根拠付きフィードバックを使うレビューと反復の判断方法
- 製品の役割、レビューと修正のループ、独立したマージ前の条件を示す3つの静的な図解
- 過大に伝えないための境界、持ち帰る実践、公開出典

`index.html`が管理する原本であり、そのまま配布できるArtifactです。CSS、JavaScript、Mona SansのWebフォントを内包し、ビルド、パッケージ導入、CDN、外部のフォント配信、認証、API接続を必要としません。

## 表示方法

リポジトリをcloneした後、`presentation\copilot-app-dx\index.html`をブラウザーで開きます。GitHubのファイル閲覧画面はHTMLのソース表示であり、ホストされたプレビューではありません。

GitHub Copilot Appでは、次のように依頼します。

```text
presentation\copilot-app-dx\index.htmlをBrowser Canvasで表示してください。
```

既存の**Browser** Canvasを使います。**AI Genius Slide Presenter**用Canvasとは別で、この資料は新しいCanvas extensionではありません。既存のスライドも変更しません。

ホストがローカルファイルを開けない場合は、兄弟配置の両ガイドへ移動できるよう、共通の`presentation`ディレクトリをloopbackで配信します。リポジトリルートのPowerShellで次を実行します。

```powershell
uv run --no-project python -m http.server 8765 --bind 127.0.0.1 --directory ".\presentation"
```

Browser Canvasで、このガイドは`http://127.0.0.1:8765/copilot-app-dx/`、補足は`http://127.0.0.1:8765/copilot-app-agent-merge/`を開きます。片方のガイドディレクトリだけ、またはリポジトリルート全体は配信しません。8765番ポートが使用中なら別の未使用ポートを選び、無関係のプロセスは停止しません。サーバーはターミナルに紐づけたまま使い、終了時はCtrl+Cで停止します。GitHub Pagesや外部への公開は不要です。

## ガイド間の移動

共通ヘッダーの**DXガイド / Agent Merge［補足］**で、同じCanvas・ブラウザータブ内の各ガイドの先頭へ移動します。下線付きの現在のガイドを選ぶと、このページの先頭へ戻ります。「自動化できる ≠ 常に自動化する」の説明直後のリンクは補足の機能紹介へ、補足のワークショップ本文のリンクはDXの境界の章へ移動します。ブラウザー標準の戻る・進むを利用できます。

配布時は、`index.html`を含む`copilot-app-dx`と`copilot-app-agent-merge`を兄弟フォルダーとして保持してください。各HTMLの閲覧自体は単独で完結しますが、相互リンクには両フォルダーの相対配置が必要です。`file://`でも、上記の共通ルートを使うHTTPでも移動できます。

JavaScript有効時は、固定の相互リンクだけに表示中の`lang=ja|en`と`scoutTheme=light|dark`を付けます。言語・テーマの操作や、追従対象のOSテーマが変わるとリンクも更新します。無関係のクエリー値やシミュレーションのデータは渡しません。URLの有効な言語は翻訳カタログの準備後に適用します。言語の未指定・不正値は日本語、テーマの未指定・不正値はOSに従います。英語を利用できない場合は理由を表示したまま、日本語の値を渡します。

再読み込みは最後の操作ではなく、現在のURLにある表示設定を使います。操作ボタンはそのURLを書き換えません。有効なURL指定がなければ日本語・OSテーマで再開します。Cookie、localStorage、sessionStorageなど、ブラウザーの保存領域への書き込みはありません。別の文書へシミュレーションの進行は引き継ぎません。

## 閲覧操作

- ヘッダーの**日本語 / English**で、本文・図解・操作表示・読み上げ用の名前をまとめて切り替えます。URLに有効な言語の指定がなければ日本語が初期表示です。保存領域への記録や、ブラウザー言語の自動判定は行いません。
- 英語表示では、話す一言は英語、プロンプトの回答指定は`Answer in English.`、演習リンクは英語READMEになります。日本語表示では、元の文章、`Answer in Japanese.`、日本語リンクへ戻ります。
- 切り替えてもテーマ・折り畳み・フォーカス・読んでいる内容の近くを維持します。以前のコピー通知は消しますが、クリップボードの内容は変更しません。
- 目次は広い画面で追従し、狭い画面では折り畳みになります。
- 補足説明や話す一言は、標準の開閉操作で展開できます。
- コピーボタンで一言やプロンプトをコピーできます。Clipboard APIが使えない場合は本文を選択し、手動コピーの方法を表示します。
- OSのテーマに追従します。`?scoutTheme=light`または`?scoutTheme=dark`で指定でき、テーマボタンは表示中のページだけを切り替えます。ブラウザーの保存領域へは書き込みません。
- 印刷時は補足を展開し、ナビゲーションを非表示にします。
- 印刷する言語は、現在表示している言語になります。
- JavaScriptが無効でも、日本語本文・相対リンクによるガイド間の移動・標準の折り畳みは既定のライト表示で利用できます。URLの表示設定は適用せず、言語・テーマ・印刷ボタンは表示しません。ブラウザー標準の印刷は利用できます。

## 翻訳の更新

元の日本語HTMLを初期表示と、日本語へ戻すときの原文に使います。英語は`#english-translations`内のJSONとして埋め込み、翻訳APIや外部カタログを読み込みません。

各項目は、固定の`key`、対象要素を1つだけ特定する`selector`、翻訳後の`html`や`attributes`を持ちます。ページ全体を複製せず、初期化時に既存の要素へ結び付けて日本語の内容を保持します。実行時の`data-i18n`属性で対応するキーを確認できます。

本文を更新するときは、日本語のHTMLと対応する英語の項目を一緒に更新します。構造を変えた場合はセレクターも揃えてください。翻訳対象を親子で重ねず、IDと操作部品を維持します。インラインの書式は対応する`strong`、`code`、`br`、`span`、`a`を使い、属性とリンクは反映前に検査します。JSONの構文を保ち、埋め込みカタログ内の`<`は`\u003c`として記述します。

動的な操作メッセージは`japaneseUI`とカタログの`ui`でキーを揃えます。英語の文書情報と言語別の`href`も更新対象です。製品名、コマンド、フォントデータ、英語のOFL全文は翻訳しません。

相互リンクの行き先は翻訳カタログではなく固定のナビゲーション処理が管理します。文字と読み上げ用の名前を翻訳し、カタログで`href`を上書きしたり、任意の相対URL・実行可能なURLを許すために`safeLink`を緩めたりしないでください。

英語表示を有効にする前に、切り離したDOMで翻訳結果を確認します。文章・操作名の翻訳漏れ、不正なマークアップ、曖昧なセレクター、日本語ドキュメントリンクの残存があれば、英語切り替えを無効にして理由を表示します。日本語のガイドは壊さずに利用できる状態を保ちます。

## Copilot Theme

デザインは[GitHub Brand Toolkit](https://brand.github.com/)のうち、[Color / Copilot Theme](https://brand.github.com/foundations/color)、[Copilotのブランド](https://brand.github.com/brand-identity/copilot)、[Typography](https://brand.github.com/foundations/typography)を参照しています。ワークショップ用のガイドであり、GitHubの公式製品資料やApp UIの複製ではありません。

白・黒・ニュートラルを主面に、Copilotに関係する強調へ紫、GitHubとのつながりへ緑を使います。公式の配色例はバランスの参考であり、画素数を厳密に一致させる条件ではありません。全体を紫で埋めるのではなく、内容が主役になる配色です。

| 役割 | Light | Dark |
|---|---|---|
| 主面 / 文字 | `#FFFFFF` / `#101411` | `#101411` / `#FFFFFF` |
| 補助面 | `#F2F5F3` | `#232925` |
| Copilotの強調・リンク | Purple 3 `#8534F3` | Purple 1 `#C898FD` |
| 緑の文字・図解の細部 | Green 5 `#08872B` | GitHub Green `#0FBF3E` |
| 主ボタン | Purple 3 `#8534F3`に白文字 | Purple 3 `#8534F3`に白文字 |

部品の色は既存の`--cp-*`トークンを通して指定します。公式スウォッチと、そこから導出するニュートラル・淡色をこのHTML内で割り当てており、ほかのArtifactのテーマは変更しません。GitHub Greenに小さい白文字を重ねる組み合わせは、コントラスト不足のため使いません。

冒頭は人間の判断とAIの作業の受け渡しを示します。均一なカードの一覧ではなく、つながりのある6工程と、図解を添えた6つの価値を読み進める構成です。「人間＝緑」「AI＝紫」はこのガイド内の凡例であり、GitHub公式の意味付けではありません。役割は文字と形でも伝えます。

製品の役割マップ、レビューのループ、マージ前の条件図はCSSとインラインSVGで構成しています。ラベルはHTMLの文字として保持し、狭い画面では縮小せずに配置を組み替えます。関係を説明する静的な図であり、実際のPR状態の表示や操作は行いません。特にthread解決、Draft解除、リポジトリのルール確認は独立した条件であり、同じ操作や自動マージの手順としては示しません。

### 文字組みと埋め込みフォント

英字には、未改変・標準幅のMona Sans可変Webフォントを使います。日本語はOSの日本語書体、コードはOSの等幅書体に切り替わります。CondensedやExpandedへの置換、装飾的な合字、強い字間調整は避けてください。

| フォントの出典 | 値 |
|---|---|
| リポジトリ | [github/mona-sans](https://github.com/github/mona-sans) |
| 固定リビジョン | `0f7dc66ddd766605eb0e75c3f47bf9d1dd38ceca` |
| 元ファイル | `fonts/webfonts/variable/MonaSansVF[opsz,wght].woff2` |
| 元ファイルのサイズ | 137,252 bytes |
| SHA-256 | `62e40f6e14e5bbb97132b4513a4d97319ab6aaa46996cf46c7a9f357edadb662` |
| ライセンス | SIL Open Font License 1.1、著作権者 The Mona Sans Project Authors |

フォントは`style#embedded-font`のdata URLです。著作権表示とOFL全文はガイドの`#font-license`に折り畳みで収録し、HTMLを単独配布しても失われないようにしています。

フォントの更新手順:

1. 同じ明示的な上流リビジョンから、標準幅のWOFF2とOFLを取得します。リビジョン、元のサイズ、SHA-256を記録し、上流の`main`へ暗黙に追従させません。
2. 未改変のWOFF2をBase64化して`style#embedded-font`へ埋め込み、`#font-license`の著作権表示とライセンス全文を更新します。フォントの改変やサブセット化は行いません。
3. 英日READMEの出典情報を更新し、HTML全体を400KiB以下に保ちます。実行時のフォント読み込みはオフラインで完結させてください。

## 更新時の注意

`index.html`を直接編集し、実行時の依存はファイル内で完結させます。コンポーネントの色には`var(--cp-*)`を使い、章ID・操作名・見出し階層・キーボード操作を維持してください。

製品の仕様、ワークショップの手順、発表上の提案を区別します。製品説明を更新するときは出典と参照日も更新します。レビューの説明は、特定の実行履歴ではなく、受入条件、根拠、期待する動作、再現手順またはテストを結び付ける再利用可能な内容にします。

PrivateリポジトリURL、トークン、ローカル絶対パス、GitHubへの実操作は埋め込みません。公開出典へは読者がリンクを開いた場合だけ接続します。閲覧と基本操作はオフラインで使えます。

変更後はブラウザーでlight/dark、広い画面と狭い画面、目次、コピーと手動フォールバック、印刷表示を確認します。既存のPythonスターターアプリやスライドプレゼンターは変更対象外です。
